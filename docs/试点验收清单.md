# 真实场景试点验收

本清单保留 PRD v0.2 未确定的业务条件，不用虚构数据替代。

| 条件 | 当前状态 | 所需证据 |
| --- | --- | --- |
| 一个真实知识问答场景与原始文档 | 待业务确认 | 场景名称、文档版本、数据负责人 |
| 不少于 200 条问题 | 待业务确认 | 问题、标准答案、原文位置、业务审核人 |
| 答案正确率 ≥ X% | X 待定 | 真实模型、配置快照、逐条人工/已验证裁判结果 |
| 引用准确率 ≥ Y% | Y 待定 | 引用原文定位及逐条审核 |
| 首字响应 ≤ Z 秒 | Z 待定 | 目标网络/硬件/并发下真实流式测量 |
| 部署环境 | 待选择 | Compose 或 Kubernetes 的安装、重启与恢复记录 |

软件评测中的词项匹配参考值不是业务答案正确率。引用有效性表示引用可回溯；“引用是否真正支持结论”仍需标准答案与业务审核。召回率仅在问题标有目标文档/证据时有依据，没有标注的项不计入该项分母。

试点步骤：准备并审核数据 → 入库检查解析与定位 → 配置真实模型 → 运行两套检索配置 → 逐条检查失败样本 → 业务确认质量阈值 → 在目标环境测量首字与并发 → 保留结果、版本和验收人。
