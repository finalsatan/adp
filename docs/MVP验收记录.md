## 已知边界与业务待办

- 当前为单写入实例 SQLite；不支持多副本共享写入，也未证明生产并发或容量目标。
- 扫描 PDF / 图片 OCR 未内置实现；无文本层 PDF 明确返回错误。解析服务只有可注册 OCR/VLM 扩展协议，尚未与模型管理中的 vision 模型自动联通。Office 图片、部分复杂对象的限制详见解析服务说明。
- 真实供应商模型凭据与企业身份平台未提供；已验证 HTTP/OIDC 协议链路，尚未对某个客户实际模型或身份服务进行验收。离线演示和模拟服务结果不能证明业务问答质量。
- 自动词项匹配不等于答案正确率；引用 ID 有效也不代表其支持结论。业务人员需逐条人工评审并确认质量指标。
- PRD 要求的真实场景、至少 200 条业务确认问题，以及答案、引用、首字响应 X/Y/Z 阈值仍待业务方提供。执行步骤见 [试点验收清单](试点验收清单.md)，本轮没有生成虚假业务验收结果。
- 工作流、通用 Agent、MCP、工具、Skills 和计费不在本轮首版范围。
