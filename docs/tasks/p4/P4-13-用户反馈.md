# P4-13 用户反馈

状态：待验收
前置：P4-09
被依赖：P4-16、P4-17、P4-18

## 目标

实现终端用户对回答的点赞、点踩、点踩原因与纠错内容（含取消），以及搭建者的用户反馈列表。纠错加入问答库属第六期，本卡不做。

## 依据

- 应用技术方案 12.3（用户反馈与纠错；本卡不含“纠错加入问答库”）、10（`answer_feedback` 字段）、13（反馈接口）、14（权限：反馈只对“编辑”开放）、17.3（反馈测试要点）（`python3 docs/tasks/tools/doc.py app 12`、`app 10`）
- 需求 5.4.5、5.4.6（`python3 docs/tasks/tools/doc.py prd 5.4`）
- P4-01 契约、P4-09 的回答落库、P4-05 的使用范围判断

## 要做

### 1. 反馈模块 `app/chat/feedback.py`

（补充）终端用户反馈的写入 / 取消，和搭建者反馈列表的查询。

### 2. 终端用户反馈 `PUT` / `DELETE /answers/{answer}/feedback`

- `PUT`：点赞、点踩、点踩原因、纠错内容；`DELETE` 取消（12.3）。
- `rating` 取 `up` / `down`；`reasons` 为点踩原因（选项：答案错误、没有回答问题、引用不对、其他；5.4.5，选项文字以 P4-01 契约为准）；`correction` 为纠错内容（点踩时可选填写）。
- 只能对自己会话中的回答反馈，且本人仍在该应用的使用范围内（12.3、11）；不满足返回 403（错误码以 P4-01 契约为准）。
- `answer_feedback` 表字段照应用技术方案 10：`id`、`answer_id`、`app_id`、`user_id`、`rating`、`reasons`、`correction`、`handled_qa_id`、`handled_by`、`handled_at`、`created_at`、`updated_at`。`(answer_id, user_id)` 唯一，再次点击改为更新；取消点赞 / 点踩即删除这一行。
- 本卡不写 `handled_qa_id` / `handled_by` / `handled_at`（纠错加入问答库是第六期）。
- 终端用户接口不要求控制台权限码，只要求已登录 + 使用范围判断。

### 3. 反馈列表 `GET /apps/{app}/feedback`

- 按时间倒序，可按点赞、点踩、有无纠错、是否已处理筛选；每条可打开对应的会话日志（12.3、原型 `#v-appfb`）。
- 返回：时间、用户、问题、反馈、原因、纠错内容、状态（未处理 / 已加入问答库）、会话与回答 ID（供跳转日志）。
- 状态：本卡只有“未处理”（`handled_qa_id` 为空）；“已加入问答库”第六期。
- 顶部统计（点赞数、点踩数、其中纠错数）按 P4-01 契约返回（原型 `#v-appfb`，补充）。
- 权限：应用“编辑”（14）；仅有“查看”权限返回 403。
- 不写审计（14）。

### 4. 纠错加入问答库

- `POST /feedback/{id}:add-to-qa` 属第六期（依赖知识库第六期的问答库），本卡不做（2026-10-26 用户确认）。

### 和卡片不一致 / 自己补充的地方

1. **顶部统计按应用 + 时间范围汇总，不随点赞 / 有无纠错 / 是否已处理筛选变化**：原型 `#v-appfb` 的“点赞 86 · 点踩 12（纠错 5）”在切换筛选时保持全局，故 `summary` 只按应用与 `range` 统计；验收里“与列表数据一致”按“同一时间范围内、不加这三项筛选时的数据”理解。若要随筛选变化，改动只在 `feedback.list_app_feedback` 一处。
2. **改点赞时清空 `reasons` / `correction`**：契约里二者“只有点踩时有意义”，避免从点踩改点赞后残留。
3. **`answer_excerpt` 截断 200 字**：卡片与契约未给长度，纯展示用；常量 `ANSWER_EXCERPT_LENGTH`。
4. **“有纠错”把空串也算没有**：`has_correction` 按 `correction` 非 `null` 且非空判断。
5. **取消点赞 / 点踩幂等**：没有反馈时 `DELETE` 也返回 204（卡片只说“取消即删除这一行”）。
6. **`POST /feedback/{id}:add-to-qa` 不实现**：按 2026-10-26 决定，第四期没有该路由（P4-01 契约里也没有），调用返回 404；第六期再加。
