## 要做

### 1. 枚举（`app/apps/schemas.py` 与 `app/chat/schemas.py`，中文名放代码里的字典）

- `AppType`：`kb_qa`（知识问答）。工作流、智能体待细化，本卡不定义（补充：不生成用不上的类型）。
- `AppStatus`：`unpublished`（未发布）、`published`（已发布）、`disabled`（已停用）。由 `published_version_id` 是否为空和资源启停状态推导（应用技术方案 10）。
- `UsageScopeType`：`platform`（全平台）、`orgs`（指定组织）、`users`（指定用户）（需求 5.4.3）。
- `UsageTargetType`：`org`、`user`（`app_usage_targets.target_type`）。
- `AnswerKind`：`generated`（模型回答）、`qa_direct`（直接回答，第六期）、`fallback`（兜底）、`chitchat`（闲聊）（应用技术方案 6.4）。
- `AnswerStatus`：`generating`（生成中）、`done`（已完成）、`stopped`（已中断）、`failed`（失败）（应用技术方案 9.2）。
- `FeedbackRating`：`up`（点赞）、`down`（点踩）。
- `FeedbackReason`：`wrong_answer`（答案错误）、`not_answered`（没有回答问题）、`wrong_citation`（引用不对）、`other`（其他）（选项为补充，照需求 5.4.5 与原型 `#v-chat`）。
- `CitationType`：`qa`（问答对，第六期）、`doc`（文档分块）。
- `StepName`：`intent`（意图识别）、`rewrite`（问题改写）、`retrieve`（检索）、`rerank`（重排）、`generate`（生成回答）、`suggest`（追问建议）（应用技术方案 9.1；`suggest` 第六期生效）。
- `CitationRender`：`pdf`、`markdown`、`snapshot`（引用预览的呈现方式；`table`、`image` 随知识库第五期开放，第四期不定义，补充，见 §7）。

### 2. 应用配置 `AppConfig`（`app/apps/config.py`，Pydantic）

配置是一个 JSON，字段照应用技术方案 5.1，按 `app_type` 用判别联合（本阶段只有 `kb_qa`）。**允许不完整的配置**（保存草稿只做格式校验），所以除 `schema_version`、`app_type` 外都可为空/有默认值；发布校验（P4-04）再检查必填项。

- `AppConfig`：`schema_version`（默认 1）、`app_type`、`model: AppModelConfig | null`、`system_prompt`（默认空串）、`intent: AppIntentConfig`、`rewrite: AppRewriteConfig`、`memory_turns: int | null`、`knowledge: AppKnowledgeConfig`、`reply: AppReplyConfig`。
- `AppModelConfig`：`chat_model_id: int | null`、`temperature`（默认 0.3）、`max_tokens: int | null`、`thinking`（默认 false）。
- `AppIntentConfig`：`enabled`（默认 true）、`model_id: int | null`（null 表示同回答模型）。
- `AppRewriteConfig`：`enabled`（默认 true）、`model_id: int | null`。
- `AppKnowledgeConfig`：`kbs: list[AppKbRef]`（默认空）、`doc: AppDocConfig`、`qa: AppQaConfig`。
- `AppKbRef`：`kb_id`、`retrieval: RetrievalConfig | null`（null 表示用知识库默认配置）、`filter: AppKbFilter | null`、`qa_category_ids: list[int]`（默认空，问答库分类，第六期）。
- `AppKbFilter`：`folder_ids: list[int]`（默认空）、`metadata: MetadataGroup | null`（复用 P3-01 的一层“且/或”，不嵌套）。
- `AppDocConfig`：`top_k`（默认 20）、`score_threshold: float | null`、`rerank: AppRerankConfig`、`neighbor_chunks`（0–3，默认 0；相邻分块扩展第五期，第四期接收但不生效）。
- `AppRerankConfig`：`enabled`（默认 false）、`model_id: int | null`、`keep`（默认 5）。
- `AppQaConfig`：`direct: AppQaDirectConfig`、`recall_threshold: float | null`、`recall_count`（默认 3）、`rerank: AppQaRerankConfig`。**问答库召回与直答第六期，第四期只保存/校验配置，运行时不生效**（用户 2026-10-26 决定）。
- `AppQaDirectConfig`：`enabled`（默认 true）、`threshold: float | null`。
- `AppQaRerankConfig`：`enabled`（默认 false）、`model_id: int | null`。
- `AppReplyConfig`：`fallback_text`（默认“未检索到相关知识，无法回答该问题。”）、`opening`（默认空串）、`opening_questions: list[str]`（默认空）、`suggestions`（默认 false，第六期生效）、`allow_download`（默认 false）。
- 默认值：`memory_turns`、`doc.score_threshold`、`qa.direct.threshold`、`qa.recall_threshold` 配置里存 `null` 时运行时取代码常量。占位值先取 `DEFAULT_MEMORY_TURNS = 5`、`DEFAULT_DOC_SCORE_THRESHOLD = 0`、`DEFAULT_QA_DIRECT_THRESHOLD = 0.9`、`DEFAULT_QA_RECALL_THRESHOLD = 0.6`（补充，**待实测**：应用技术方案 17.1 的实测由人做，不阻塞开发，实测后只改常量不迁移数据；`score_threshold` 取 0 与 P4-07 一致）。

- `CitationOut`：`n`、`type`、`kb_id`、`kb_name`、`score`；问答对另有 `qa_id`、`question`、`answer`、`direct`（第六期）；文档另有 `doc_id`、`doc_name`、`file_type`、`chunk_ids: list[int]`、`generation`、`content`、`positions`、`edited`（应用技术方案 8.2）。
- `FeedbackIn`：`rating`、`reasons: list[FeedbackReason]`（默认空，只有点踩时有意义）、`correction: str | null`（最多 2000 字）。
- `FeedbackOut`：`id`、`answer_id`、`rating`、`reasons`、`correction`、`created_at`、`updated_at`。
- `TraceOut`：`answer_id`、`app_id`、`created_at`、`steps: list[TraceStepOut]`。`TraceStepOut`：`name: StepName`、`started_at`、`duration_ms`、`input`、`output`、`model_id: int | null`、`model_name: str | null`、`input_tokens: int | null`、`output_tokens: int | null`、`prompt_version: str | null`（结构为补充；召回/融合/重排各阶段存分块 ID、文档名、分数、前 100 字，最终提示词存全文，应用技术方案 10）。

#### 引用预览

- `CitationPreviewOut`：`render: CitationRender`、`file_type`、`kb_id`、`kb_name`、`doc_id`、`doc_name`、`page_no: int | null`、`pages: list[int]`（PDF 被引用页）、`positions`（坐标，PDF 高亮用，复制自分块）、`content: str | null`（Markdown 片段 / 快照片段）、`elements: list[CitationElementOut] | null`（Word：片段元素，带 `highlight` 标记）、`generation`、`edited`、`stale`（文档已重新入库）、`note: str | null`（“人工修改内容”“原文已更新”“该类型暂不支持预览”）、`download_allowed`。
- `CitationElementOut`：`ref`、`type`、`text`、`highlight: bool`（复用 P3-14 的元素结构）。
- `GET .../citations/{n}/preview` 的响应类型按文件类型区分（补充，见“问题”）：PDF、PPT 返回只含被引用页的 `application/pdf`；Word（`doc` / `docx`）返回 `CitationPreviewOut`（`render=markdown`）；其余类型第四期先不支持，返回 `CitationPreviewOut`（`render=snapshot`，`note` 注明类型暂不支持），随知识库第五期开放（应用技术方案 17.2、P4-10）。OpenAPI 用 `responses` 同时描述 `application/json` 与 `application/pdf`。
- `GET .../citations/{n}/file`：返回原文件，支持 HTTP Range（复用 P3-14 的 `stream_document_file` 思路）；要求当前发布版本 `allow_download=true`，否则 403 `DOWNLOAD_NOT_ALLOWED`。`download=true` 时加 `Content-Disposition: attachment`。
