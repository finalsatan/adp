在回答流程里按应用配置检索文档库：多知识库、多向量化模型、按库覆盖检索配置与过滤、重排；复用 P3-13 的检索服务，产出供提示词组装（P4-08）和引用快照（P4-10）使用的候选分块。

## 要做

### 1. 检索函数 `app/chat/retrieval.py`

提供一个异步函数（补充，入参与返回以 P4-06 的运行上下文和 P4-08 的需要为准），做文档库的“召回并融合”和“重排”，把每一步写进处理过程记录器，返回候选列表和分阶段结果。

### 2. 参与的知识库与查询文本

- 取应用配置 `knowledge.kbs` 里 `kind=doc` 的库；`kind=qa` 的问答库第六期才做，本卡跳过、不召回（6.3、17.2）。
- 已停用的知识库跳过（6.3、5.1.3）；全部跳过时返回空候选（由 P4-06 决定回复兜底话术）。
- 查询文本：意图识别、问题改写都开启且改写成功时用改写后的问题，否则用原问题（6.3）。原问题/改写后的问题由 P4-06 的运行上下文提供。

### 3. 每库的检索配置与过滤

- 检索配置：`kbs[].retrieval` 非空时覆盖该知识库默认配置，为 null 时用知识库默认配置（5.1、12.1）。
- 过滤条件 `kbs[].filter`：文档库按文件夹（含下级）和元数据（一层“且/或”，不嵌套）转换成 `recall_and_fuse` 的 `folder_id` / `metadata`（5.1、12.3；不嵌套的约定见 2026-10-25 用户决定）。

### 4. 向量化缓存

- 一次提问内建一个 `vector_cache: dict[model_id, list[float]]`，传给 `recall_and_fuse`，同一个向量化模型只调用一次（6.3、12.1）。问答库第六期接入时共用这份缓存，本卡先把参数留好。

### 5. 重排与阈值

- 文档库公共设置取 `knowledge.doc`：`top_k`、`score_threshold`、`rerank{enabled, model_id, keep}`、`neighbor_chunks`。
- 开启重排：每个文档库各取融合分最高的前 `top_k` 个候选，合在一起交给 `rerank_and_expand`（重排模型 `rerank.model_id`，保留 `keep` 条），阈值 `score_threshold` 作用于重排分数（6.3、17.3）。
- 未开启重排：所有文档库必须使用同一个向量化模型（保存草稿与发布时校验，在 P4-04）；合并后按融合分过 `score_threshold`，取前 `top_k`（6.3、17.3）。
- 相邻分块扩展 `neighbor_chunks` 属第五期：本卡接收但不生效（17.2，2026-10-26 用户确认）。

### 6. 阈值默认值

- `score_threshold`、`top_k` 等配置里为 null 时取代码里的占位默认值，集中放在一处并标“待实测”（应用技术方案 17.1 的实测由人做，不阻塞开发；2026-10-26 用户确认）。`top_k` 用配置格式示例里的 20，`score_threshold` 用 0（补充）。

### 7. 复用 P3-13 的两段函数

- `recall_and_fuse` 与 `rerank_and_expand` 目前把模型用量来源写死为 `kb_hit_test`（P3-13）。本卡给两个函数加可选参数 `source`（默认 `kb_hit_test`）和 `source_id`（默认 `None`），回答流程传 `source="app"`、`source_id=应用 ID`；命中测试（P3-13）不传，行为不变（技术方案 14、应用技术方案 14；补充）。
- 除上面这一个参数外不改检索算法；分数、阈值、过滤、去重逻辑照 P3-13。

### 8. 降级（6.5）

- 向量化或召回失败的单个知识库跳过，其余照常；全部知识库都失败时抛 `RETRIEVAL_FAILED`（不回复兜底话术）。
- 重排调用失败抛 `RETRIEVAL_FAILED`，不退回按融合分排序（混用不同向量化模型时融合分不可比）。

### 9. 处理过程与候选结构

- 处理过程记：每库的向量召回条数、全文召回条数、融合条数、重排保留条数、各阶段耗时、命中的分块 ID / 文档名 / 分数 / 前 100 字（应用技术方案 10 的 `answer_traces` 结构、6.1）。
- 候选字段至少含：`kb_id`、`kb_name`、`doc_id`、`doc_name`、`file_type`、`chunk_ids`（相邻分块扩展后可能多块）、`generation`、`content`、`title_path`、`positions`、`edited`、`score`（重排分或融合分）、`priority`（文档库为普通优先级）（8.2 引用快照字段，供 P4-08/P4-10 用）。
