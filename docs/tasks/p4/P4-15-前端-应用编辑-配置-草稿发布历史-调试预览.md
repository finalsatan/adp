# P4-15 前端：应用编辑（配置、草稿发布历史、调试预览）

状态：待开始
前置：P4-01（联调需要 P4-04、P4-11，以及 P4-06～P4-09 的回答流程）
被依赖：P4-16（复用本卡的对话组件）、P4-18

## 目标

做出应用的“配置与调试”页：表单配置模型、提示词、知识库与检索、回答设置；保存草稿、发布校验与发布、发布历史与恢复；右侧调试预览用 SSE 走通草稿配置并展开处理过程。

## 依据

- 需求 5.1.2（回答流程）、5.1.3（知识库与检索配置）、5.1.4（模型、提示词与对话设置）、5.1.5（调试）、5.4.3（版本与发布）
- 应用技术方案 5（配置格式、草稿发布回滚、发布校验、引用登记）、6（回答流程）、7（提示词与上下文）、8（引用）、9（流式输出与生成控制）、12.1（调试预览）、13（接口清单）、14（权限、审计与用量）、15（前端）、17.1（默认值待实测）
- 原型 `#v-app`、`#m-publish`、`#v-appver`
- P4-01 契约（配置 JSON、草稿与版本接口、SSE 事件、错误码）

## 要做

### 1. 配置与调试页（照原型 `#v-app`）

- 页头复用 P4-14 的 `AppHeader`；右上“保存草稿”“发布”；草稿相对当前发布版本有修改时显示“草稿有未发布的修改”（比较配置哈希，以 P4-01 契约为准）。
- 保存草稿调 `PUT /apps/{app}/draft`，带 `draft_revision`；返回 409 `DRAFT_CONFLICT` 时提示“草稿已被他人修改，请刷新后重试”，不覆盖。
- 配置结构照应用技术方案 5.1 的 JSON，字段名与校验以 P4-01 契约为准。

### 2. 模型与提示词

- 回答模型（只列已启用的对话模型）、温度、最大输出；深度思考第六期，本期不显示（用户决定）。
- 系统提示词：多行文本，说明“只写角色、语气和回答要求。参考内容、引用标注要求、历史对话和当前问题由系统拼接，不能修改”；“查看系统拼接的部分”调 `GET /apps/{app}/prompt-preview` 只读展示；“恢复默认模板”。
- 问题理解：意图识别（开关、模型，默认同回答模型）、问题改写（开关、模型）；说明“两步都开启时并行执行”“改写提示词本阶段不开放修改”。
- 记忆轮数：先用占位值并标“待实测”（应用技术方案 17.1，用户决定）。

### 3. 知识库与检索

- “添加知识库”调 `GET /apps/{app}/kb-candidates`，只列出操作人能查看、应用能引用的知识库；本期只展示文档库（问答库第六期，用户决定；以 P4-01 契约为准）。
- 已选知识库列表：显示向量化模型、检索方式（向量/全文/混合）与权重、是否覆盖默认配置、过滤条件；可“恢复为知识库默认”、移除。
- 文档库检索（作用于所有文档库合并后的结果）：Top K、分数阈值（占位并标“待实测”）、重排（开关、重排模型、保留条数）。相邻分块扩展第五期，本期隐藏（用户决定；应用技术方案 17.2）。
- 所选文档库使用不同向量化模型时必须开启重排才能保存，按原型显示提示。
- 过滤：文档库按文件夹、元数据一层“且/或”多条件（不嵌套）；控件与 P3-17 命中测试页一致。

### 4. 回答设置

- 兜底话术、开场白、开场推荐问题；允许下载原文件（默认关闭）。追问建议第六期，本期不显示（用户决定）。

### 5. 预览调试（照原型 `#v-app` 右侧）

- 使用当前草稿配置，请求带 `draft_revision`（与库中不一致时提示先刷新）；历史由前端随请求带上，最多最近 20 轮（后端再按记忆轮数截取）。
- 新建共用对话组件 `frontend/src/components/chat/`：读取 SSE（复用 `frontend/src/lib/sse.ts`，扩展 `KNOWN_EVENT_TYPES` 支持 `STEP_STARTED`、`STEP_FINISHED`、`CITATIONS`、`SUGGESTIONS`、`TRACE` 等 P4-01 定义的事件）、按累积全文解析引用角标（应用技术方案 8.1：`[1]`、`[1][2]`、跨片段、全角 `【1】`、超范围编号按普通文字）、停止生成、复制、重新生成；用 `SafeMarkdown` 渲染回答（应用技术方案 7.2）。终端用户对话页（P4-16）复用同一组件，debug 模式多一个“处理过程”展开区。
- 处理过程：按步骤显示意图识别、问题改写、问答库/文档库召回与重排、提示词（“查看完整提示词”）、模型调用（耗时、Token 数）；数据来自 SSE 的 `STEP_*` 与 `TRACE` 事件（以 P4-01 契约为准）。
- 点召回结果查看位置：调 `GET /apps/{app}/debug/chunks/{chunk}/preview`，复用 P3-18 的 PDF / 解析结果预览组件；模型用量来源 `app_debug`。

### 6. 发布与发布历史

- 发布弹窗 `#m-publish`：版本说明、使用范围提示（“在‘权限与设置’中修改”）、对话页链接；调 `POST /apps/{app}:publish`；校验失败（422 `PUBLISH_CHECK_FAILED`）时在弹窗里列出问题清单（应用技术方案 5.3）。
- 发布历史页 `#v-appver`：版本号、版本说明、发布人、发布时间、操作“查看配置 / 恢复为草稿”；恢复调 `POST /apps/{app}/versions/{v}:restore`。当前版本标“当前”。
