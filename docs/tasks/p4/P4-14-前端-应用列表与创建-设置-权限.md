# P4-14 前端：应用列表与创建、设置、权限

状态：待开始
前置：P4-01（联调需要 P4-03、P4-05）
被依赖：P4-18

## 目标

做出控制台“应用开发 → 应用”的列表页、新建弹窗、设置页（基本信息）与权限页（使用范围、可见范围、协作者、停用删除），搭建者能创建知识问答应用并把它发布前的基本信息和权限配好。

## 依据

- 需求 5.4.1（概念与范围）、5.4.2（应用管理）、5.4.6（权限）、5.4.7（审计与用量）
- 应用技术方案 10（`apps` / `app_usage_targets` 表）、11（使用范围与终端用户入口）、13（接口清单）、14（权限、审计与用量）、15（前端）
- 技术方案 v0.1 6.2（资源与协作者）、7.1、7.3（权限码、资源权限）、10（接口约定）
- 原型 `#v-apps`、`#d-newapp`、`#v-appperm`
- P4-01 契约（应用接口、`can_*` 字段、错误码）

## 要做

### 1. 菜单与路由

- 在 `frontend/src/lib/menu.ts` 的“应用开发”分组加“应用” `/apps`，权限码以 P4-01 契约为准（应用没有专属查看权限码，列表/详情靠资源权限过滤；菜单用 `console.use`，补充）。
- 路由（补充）：`/apps` 列表；`/apps/:id/settings` 设置（基本信息）；`/apps/:id/permissions` 权限。配置与调试、发布历史、对话日志、用户反馈分别由 P4-15、P4-17 挂到同一应用页头下。
- 新建 `frontend/src/pages/apps/AppHeader.tsx`：应用页头（名称、类型、可见范围、发布状态、当前版本、创建人、草稿有修改标记）+ 页签“配置与调试 / 发布历史 / 对话日志 / 用户反馈 / 权限与设置”，供 P4-15、P4-17 复用（照 P3-15 的 `KbHeader`）。
- 新建 `frontend/src/pages/apps/api.ts`：应用相关类型别名与中文文案（类型、发布状态、使用范围、可见范围）、列表查询参数与筛选选项、全部接口 hook（列表/详情/新建/编辑/启停/删除/可见范围/使用范围/协作者/引用清单）。

### 2. 列表页（照原型 `#v-apps`）

- 页头说明照原型；有 `resource.create` 权限时显示“新建应用”按钮。
- 筛选：类型（本阶段只有知识问答）、发布状态（未发布/已发布/已停用）、可见范围、所属组织、关键字；右侧“我能查看的 N 个”。
- 列：名称（含描述）、类型、发布状态（已发布且有草稿修改时显示“草稿有修改”）、当前版本（`v3 · 10-21`）、可见范围、使用范围、所属组织、创建人、更新时间、操作。
- 操作：配置（进入 P4-15 的配置页）、对话页（打开 `/chat/{id}`，P4-16）、`···`（发布历史、对话日志、用户反馈、权限与设置、停用/启用、删除）。按接口返回的 `can_*` 显示；安全以后端为准。
- 分页与空状态。
- 停用与删除的确认文案照原型 `#v-appperm` 的“停用与删除”区块（停用后终端用户打不开、“我的应用”中也不显示；删除后会话、日志和反馈保留在系统中）。

### 3. 新建弹窗（照原型 `#d-newapp`）

- 字段：类型（知识问答可选；工作流、智能体显示“待细化”并禁用）、名称、描述、可见范围（仅自己/本组织/全平台）。
- 系统管理员另选所属组织（照 P3-15 的 `KbCreateModal`，补充）。
- 文案照原型：“控制谁能在控制台看到这个应用。谁能使用在发布前设置‘使用范围’。”
- 名称在同一组织内唯一，重名返回 409 `NAME_CONFLICT`，显示在名称输入框下。
- 提交成功后进入配置页（补充）。

### 4. 设置页（基本信息）

- 名称、描述可改；类型只读并提示“创建后不可修改”。
- 调 `PATCH /apps/{id}`。

### 5. 权限页（照原型 `#v-appperm`）

- 使用范围：全平台 / 指定组织（含下级，说明照原型）/ 指定用户；调 `GET/PUT /apps/{app}/usage-scope`。系统管理员不属于任何组织，只有“全平台”或被列入用户名单时才在范围内（应用技术方案 11）；修改后立即生效、不需要重新发布。
- 可见范围：复用 P1-12 的 `VisibilityModal`（`frontend/src/components/resource/VisibilityModal.tsx`），`RESOURCE_IN_USE` 时列出受影响的应用。
- 协作者：复用 P1-12 的 `CollaboratorsDrawer`（`frontend/src/components/resource/CollaboratorsDrawer.tsx`），文案照原型。
- 停用与删除区块：说明文案与按钮照原型；停用/启用调 `POST /apps/{id}:disable` / `:enable`，删除调 `DELETE /apps/{id}`。

### 6. 权限与显示

- 用 `GET /api/v1/me` 的权限码和接口返回的 `can_*` 控制按钮显示（查看、编辑、管理三类，应用技术方案 14）；终端用户角色看不到“应用开发”菜单。
- 控制台顶栏的“我的应用”入口由 P4-16 加（应用技术方案 11）。
