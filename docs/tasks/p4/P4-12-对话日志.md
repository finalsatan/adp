# P4-12 对话日志

状态：已验收
前置：P4-09
被依赖：P4-17、P4-18

## 目标

实现搭建者的对话日志：按会话列出、打开会话回放每一问的全部回答和处理过程，以及在日志中查看引用分块的位置。

## 依据

- 应用技术方案 12.2（对话日志）、10（存储设计）、13（日志接口）、14（权限：日志只对“编辑”开放）、17.3（日志测试要点）（`python3 docs/tasks/tools/doc.py app 12`、`app 10`）
- 需求 5.4.5、5.4.2、5.4.6（`python3 docs/tasks/tools/doc.py prd 5.4`）
- P4-01 契约、P4-10 的公共预览函数、P4-09 的落库

## 要做

### 1. 会话列表 `GET /apps/{app}/logs/conversations`

- 按会话列出：用户、所属组织、会话标题、开始时间、轮数、版本、有无点踩；可按时间、有无反馈筛选（12.2、原型 `#v-applog`）。
- 列表通过会话所属的应用过滤；点踩筛选按 `answer_feedback` 查（10）。
- 权限：应用“编辑”（14）。
- 分页与筛选参数以 P4-01 契约为准。

### 2. 会话回放 `GET /apps/{app}/logs/conversations/{conv}`

- 按顺序显示每一问的全部回答（含重新生成前的旧回答）和处理过程（12.2）。
- 处理过程来自 `answer_traces`（P4-09 落库），结构见应用技术方案 10；旧回答标注“已重新生成”。
- 权限：应用“编辑”。

### 3. 日志中引用预览 `GET /apps/{app}/logs/answers/{answer}/citations/{n}/preview`

- 权限同 12.1（应用“编辑”，只放行该应用引用的知识库中的文档）；搭建者能看整份还是只看被引用部分，按其本人对知识库的查看权限决定（12.2、8.3 末条）。
- 复用 P4-10 的公共预览函数。

### 4. 保留与删除（12.2）

- 本阶段永久保存，会话、问答、处理过程和反馈都不自动清理；系统设置中不设保留时长。
- 删除应用后：应用是软删除，它的会话、处理过程和反馈全部保留，控制台和对话页都不再能打开，日志接口不再返回（5.4.2）。
- 终端用户删除会话后：日志列表照常显示该会话，标注“用户已删除”（5.4.5）。
- 日志接口是只读接口，不写审计（14）。

### 和卡片不一致 / 自己补充的地方

1. **版本取最后一条回答的版本**、**引用库按 `resource_refs` 判断**：见“问题”一节，均为待确认（不阻塞）。
2. **时间筛选按 `chat_answers.created_at`**：应用技术方案 10 明确“最近 7 天按 `chat_answers.created_at` 查”，故用 EXISTS（会话里至少一条回答落在范围内），而不是按会话 `created_at` / `last_active_at`。
3. **列表排序按 `last_active_at` 倒序**：与终端用户会话列表一致；文档未指定排序。
4. **日志引用预览的 `download_allowed` 传 `False`**：日志只有预览接口、没有下载接口，避免未发布应用读当前发布版本时报错。
5. **回答不属于该应用 / 引用编号不存在返回 404**：前者不暴露存在性，后者由 `citations.get_citation` 抛 `CITATION_NOT_FOUND`。
