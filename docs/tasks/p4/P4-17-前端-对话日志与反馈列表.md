# P4-17 前端：对话日志与反馈列表

状态：待验收
前置：P4-01（联调需要 P4-12、P4-13）
被依赖：P4-18

## 目标

做出应用的“对话日志”和“用户反馈”页：按会话回放每一问的全部回答和处理过程、点分块看位置；反馈列表筛选、打开对应日志。本阶段只到“看日志和反馈”，纠错加入问答库属第六期。

## 依据

- 需求 5.4.5（对话日志与用户反馈）、5.4.6（权限：日志和反馈要求“编辑”）
- 应用技术方案 12.2（对话日志）、12.3（用户反馈与纠错）、13（接口清单）、14（权限）、15（前端）
- 原型 `#v-applog`、`#v-appfb`
- P4-01 契约；P4-15 的处理过程展示（复用）；P3-18 的 `PdfPreview` / `ParseResultView`（分块位置预览复用）

## 要做

### 1. 对话日志页（照原型 `#v-applog`）

- 左侧会话列表：调 `GET /apps/{app}/logs/conversations`；筛选时间（最近 7 天等）与有无反馈（全部 / 有点踩）；显示用户、所属组织、会话标题、开始时间、轮数、版本、有无点踩；终端用户已删除的会话标注“用户已删除”。
- 会话详情：调 `GET /apps/{app}/logs/conversations/{conv}`，按顺序显示每一问的全部回答（含重新生成前的旧回答，标“已重新生成”）和处理过程；处理过程复用 P4-15 的只读展示组件。
- “查看完整提示词”显示处理过程里保存的最终提示词全文（应用技术方案 7.1）。
- 点处理过程中的分块查看位置：`GET /apps/{app}/logs/answers/{answer}/citations/{n}/preview`，复用 P3-18 的预览组件；搭建者能看到整份原文还是只看被引用部分，按其对该知识库的查看权限决定（应用技术方案 8.3 末条）。
- 只有应用的“编辑”权限能读日志，仅“查看”权限返回 403（应用技术方案 14）；接口返回 403 时显示无权限提示。

### 2. 用户反馈页（照原型 `#v-appfb`）

- 统计：点赞数、点踩数（含纠错数）；调 `GET /apps/{app}/feedback`（分页/筛选）。
- 筛选：全部 / 点赞 / 点踩 / 有纠错、状态、时间（最近 30 天等）。
- 列：时间、用户、问题、反馈、原因、纠错内容、状态、操作（对话日志）。
- “对话日志”跳到对话日志页并定位到该会话。
- “加入问答库”属第六期，本期不显示该按钮与 #d-fb2qa 弹窗；状态列本期固定显示“未处理”（用户决定；`handled_qa_id` 第六期，以 P4-01 契约为准）。

### 3. 权限

- 日志和反馈包含终端用户的提问，只对“编辑”开放（应用技术方案 14）；终端用户看不到这两个页签。
