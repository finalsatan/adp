# X04 引擎：内置文本与表格解析

状态：待验收
前置：X03
被依赖：X10

## 目标

实现 `builtin` 引擎中 TXT、CSV、TSV、Excel 的部分（Markdown、HTML 的部分用 Docling 的解析器，在 X06 实现）。

## 依据

- 知识库技术方案 6.2 的“内置表格解析”“内置文本解析”两行、7（Excel、CSV 的表格元素保留工作表名和原始行号）、13（Excel、CSV 的定位：工作表和行范围）
- 需求 4.1.4 的“表格”一条、4.1.8 的 Excel、CSV 一行

## 要做

### 1. TXT

- 用 charset-normalizer 识别编码（覆盖 UTF-8、UTF-8 BOM、GBK、GB18030），按空行分段，每段一个段落元素。没有页码。

### 2. CSV、TSV

- 编码识别同上；csv 用逗号、tsv 用制表符（csv 文件实际是分号分隔时，用 `csv.Sniffer` 判断，补充）。
- 按表格设置的 `header_row`（默认 1）取表头，其上的行丢弃。整个文件一个表格元素。

### 3. Excel（xlsx；xls、ods 由 worker 先转成 xlsx，X02）

- pandas + openpyxl 读取；`sheets` 为 `all` 或工作表名列表（需求 4.1.4：默认全部）。
- 每个工作表一个表格元素；按 `header_row` 取表头。
- 合并单元格：值向下填充（知识库技术方案 6.2）。横向合并的单元格在表格结构里保留为跨列单元格（补充）。
- 隐藏的工作表默认也处理（补充：文档没提，按“全部”理解），在完成记录里提一句。
- 公式单元格取计算后的值（openpyxl `data_only=True`）；没有缓存值的公式取空（补充）。

### 4. 位置信息（关键）

知识库技术方案 7 要求表格元素保留工作表名和原始行号，13 节要求引用定位到“工作表 + 行范围”。约定（补充，先读 Docling 自带 Excel 解析器的源码确认它的做法，能沿用就沿用）：

- 每个工作表一页：`page_no` = 工作表序号（从 1 开始），页面上记录工作表名。
- 表格的每个数据行能还原出原始的 Excel 行号：**不删除表格中间的空行**；如果实现上必须删除，就另存一份“表格行 → 原始行号”的映射，放在 DoclingDocument 允许的扩展位置。
- 具体存放位置写进完成记录，第三期的分块代码要按它取行号。

### 5. 引擎注册

`builtin` 引擎在本卡支持 `txt`、`csv`、`excel`；`markdown`、`html` 在 X06 加上后才算完整。`availability()` 恒为可用。

### 位置信息约定（第三期按此取）

1. **工作表 → 页**：`page_no` 从 1 开始，按工作簿顺序只数被选中的工作表；每个工作表 `add_page(page_no, size=(0, 0))`。
2. **工作表名**：两处都写。按 Docling 的做法，在表格的父节点建一个 `GroupLabel.SHEET` 的组，组名是工作表名；同时在表格元素的 `meta` 自定义字段 **`adp__sheet_name`** 里再存一份，方便分块代码直接取。
3. **表格行 → 原始行号**：存在**表格元素的 `meta` 自定义字段 `adp__row_numbers`** 里，是一个整数列表，长度等于 `table.data.num_rows`，第 i 个元素是第 i 个网格行在源文件里的 1 起算行号。表格中间的空行不删除，所以列表是连续的 `header_row, header_row+1, ...`（表头行本身也算一行）。CSV、TSV 用同一个字段，行号是文件里的行号。
4. **取法**：`table.meta.get_custom_part()["adp__row_numbers"][i]` 得到原始行号，`["adp__sheet_name"]` 得到工作表名。`doc.json` 导出再加载后这两个字段仍在（有测试）。
5. 表格元素还带 `prov`（`page_no` = 工作表序号，坐标全 0，因为 Excel、CSV 没有页面坐标）。

读了 GitHub 上 Docling 的 `docling/backend/msexcel_backend.py`：它用工作表序号做 `page_no`、用 `GroupLabel.SHEET` 组的 `name` 放工作表名、用表格 `prov` 的 bbox（TOPLEFT）编码起始行/列。前两条沿用了；第三条没沿用——本项目的 `doctools.add_table` 统一用 PDF 坐标（BOTTOMLEFT），而且我们要保留表格中间空行、还允许丢弃表头以上的行，`meta` 里的显式行号列表更直接。

### 和卡片不一致 / 补充实现细节

- **工作表名的存放**：卡片写“页面上记录工作表名”，但 `PageItem` 没有名字字段，所以按 Docling 的做法放在 `GroupLabel.SHEET` 组的 `name` 上，并在表格 `meta` 里再存一份（见上）。
- **合并单元格**：先按 openpyxl 的合并区域做纵向向下填充（不保留跨行结构），横向合并保留为跨列单元格；跨行又跨列时每一行保留一个跨列单元格。
- **公式**：pandas/openpyxl 都用 `data_only=True`，公式取计算后的缓存值，没有缓存值为空。
- **隐藏工作表**：默认也处理（`workbook.sheetnames` 和 pandas `sheet_name=None` 都含隐藏表），按卡片“全部”的理解，未单独写测试。
- **Excel 只解析 xlsx**：`supports("excel", ext)` 对 xls、xlsx、ods 都返回 True（类型层面，`/v1/engines` 才能列出 excel）；实际解析非 xlsx 时返回 `UNSUPPORTED_TYPE`，说明先转 xlsx。xls、ods 由 worker 先转换（X02）。
- **CSV 行号**：用 `csv.reader` 的行序（1 起算）。字段内带换行的 CSV 行号可能与物理行号不一致，暂按行序处理。
- **`engine_version`**：`builtin-0.1`。
- **`pages`**：Excel 等于被选中的工作表数；TXT、CSV/TSV 为 0（没有页码）。
