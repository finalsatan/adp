# P2-10 前端：模型体验

状态：待开始
前置：P2-01（联调需要 P2-07）
被依赖：P2-12；第四期的对话页复用本卡的 SSE 读取工具和 Markdown 渲染组件

## 目标

做出模型体验页：选择最多 4 个对话模型并排对比，流式显示回答，可停止、清空。同时做出可复用的 SSE 读取工具和安全的 Markdown 渲染组件。

## 依据

- 需求 3.6
- 技术方案 9.6
- 应用技术方案 7.2（回答渲染不渲染原始 HTML 和图片——本卡的 Markdown 组件按同样规则做，第四期直接用）
- 原型 `#v-play`
- 接口：`GET /models?type=chat&status=enabled`、`POST /models/{id}/chat`

## 要做

### 1. SSE 读取工具 `src/lib/sse.ts`

- `streamSSE(url, body, { signal, onEvent })`：用 P1-02 的 `fetchWithRefresh` 发 POST（JSON），返回非 2xx 时把错误 JSON 抛出；正常时用 `ReadableStream` + `TextDecoder` 读，按空行切分事件，忽略以 `:` 开头的注释行（心跳），把 `data:` 后的 JSON 解析成生成的 `SseEvent` 类型交给 `onEvent`。不认识的 `type` 直接忽略（技术方案 9.6：向前兼容）。
- `signal` 中止时停止读取并不报错（用户点了停止）。
- 不用浏览器的 `EventSource`（它只支持 GET，技术方案 9.6）。

### 2. Markdown 组件 `src/components/SafeMarkdown.tsx`

- react-markdown + remark-gfm；**不渲染原始 HTML**；图片 `![alt](url)` 只显示为链接文字，不加载图片；链接 `target="_blank" rel="noopener noreferrer"`（应用技术方案 7.2）。

### 3. 页面（照原型 `#v-play`）

- 页头：标题、说明“选择模型在线对话，最多同时对比 4 个模型。可选任何已启用的对话模型。”；右侧“添加对比模型（n/4）”“清空对话”。
- 提示条：“对话记录不保存，离开页面即清空。本页产生的调用计入用量统计。”
- 并排的模型列（1–4 列）：每列顶部是模型选择框、“参数”按钮、关闭（剩一列时不能关）。参数浮层：温度、Top P、最大输出、深度思考开关（模型 `cap_thinking` 为假时禁用并显示“模型不支持”）；说明“默认值取自模型配置，仅对本次体验生效”。
- 每列显示自己的对话：用户消息、模型回答（流式追加，用 SafeMarkdown 渲染）；思考内容折叠显示“思考过程”；回答下方一行统计“首字 0.62s · 总耗时 3.1s · 输入 18 / 输出 186 tokens”（来自 `RUN_FINISHED`）；`RUN_ERROR` 显示为红色提示“调用失败：{message}”，下面一行灰字“可在模型配置中调整超时与重试次数”。
- 底部共用输入框：回车发送（Shift+回车换行），发送时每列各发一个请求，历史各自独立（每列只带自己这一列的历史）。生成中按钮变成“停止生成”，点了中止全部请求。
- 清空对话：中止进行中的请求并清空所有列。
- 离开页面时中止进行中的请求。
