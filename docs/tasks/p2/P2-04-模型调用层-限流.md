# P2-04 模型调用层：限流

状态：已验收
前置：P2-02
被依赖：P2-05

## 目标

按模型限制 QPS 和并发；入库调用另有“入库额度”，入库和在线合计不超过模型限额。本卡只做限流组件，不调用模型。

## 依据

- 技术方案 9.3 的“限流”三条（**逐条照做**）、13.2 的“模型调用”中限流相关的几条
- 需求 3.5

## 要做

`app/gateway/ratelimit.py`：

### 1. 额度

- 每个模型两组额度：总额度（QPS = `rate_qps`，并发 = `rate_concurrency`）和入库额度（总额度 × 系统设置 `model_call.ingest_rate_ratio`，向下取整，**至少为 1**（补充））。
- 模型的 `rate_qps` 和 `rate_concurrency` 都为空时不做任何限流；只设了其中一项时只限那一项。
- 在线调用只占总额度；入库调用（`source == "ingest"`）两组都占，**两组都未超限才放行**。

### 2. 用 Lua 脚本保证原子性

- 当前时间在脚本里用 Redis 的 `TIME` 取，不用各 api 进程的本地时间（补充：多副本时钟不一致）。
- QPS：键 `rl:qps:{model_id}:{scope}:{秒}`，`INCR` 后若是 1 就 `EXPIRE 2`；超过上限则本次不算（`DECR` 回去）并返回拒绝。scope 为 `total` 或 `ingest`。
- 并发：有序集合 `rl:conc:{model_id}:{scope}`，成员为请求 id，分值为租约到期时间（当前 + 60 秒）。获取时先 `ZREMRANGEBYSCORE` 删掉已到期的，再 `ZCARD`，未超限则 `ZADD`。
- 入库调用需要同时检查两组：**一个脚本**里先检查全部键都未超限，再一起增加；任一超限则什么都不改。
- 租约时长、续约间隔做成参数（默认 60 秒、20 秒），测试里调小。

### 3. 使用方式

```python
async with limiter.acquire(model, ingest=False) as lease:
    ...  # 调用模型；流式输出期间 lease 自动每 20 秒续约
```

- `acquire` 超限时抛 `RateLimited(scope="total"|"ingest")`。调用方决定怎么处理：在线调用转成 `MODEL_RATE_LIMITED`；入库调用稍后重试、不算失败（第三期）。
- 进入后启动一个后台任务每 20 秒对自己的成员执行 `ZADD XX` 续约；退出（含异常、取消）时停止续约并 `ZREM`。退出清理不能被取消打断（用 `asyncio.shield` 或 try/finally 中同步等待）。
- 进程崩溃时不续约，租约最多 60 秒后自动失效（技术方案 9.3）。
- QPS 只在获取时计数，不需要释放。

## 完成记录

### 新建

- `backend/app/gateway/ratelimit.py`：`RateLimiter`、`RateLimited`、`Lease`。
  - 两组额度：总额度（`rate_qps` / `rate_concurrency`）与入库额度（总额度 × `ingest_ratio`，`math.floor` 后至少 1）。
  - 一次 `EVAL` 完成一个原子获取：先检查全部键（QPS + 并发、总额度 + 入库额度），全部未超限才一起 `INCR`/`ZADD`；任一超限什么都不改。在线只查 `total`，入库查 `total` 和 `ingest`。
  - 时间用 Redis `TIME`；QPS 键 `rl:qps:{model_id}:{scope}:{秒}`，`INCR` 后首次 `EXPIRE 2`；并发用有序集合 `rl:conc:{model_id}:{scope}`，成员为请求 id，分值为到期时间。
  - `acquire` 是异步上下文管理器；进入后后台任务每 `renew_interval` 秒用 `ZADD XX` 续约，退出（含异常、取消）时先停续约再 `ZREM`，清理用 `asyncio.shield` + `await finish` 保证取消时也完成。
  - 模型两个字段都为空时不访问 Redis，直接放行。
- `backend/app/gateway/lua/acquire.lua`、`backend/app/gateway/lua/renew.lua`：上面两个脚本。
- `backend/tests/gateway/__init__.py`、`backend/tests/gateway/test_ratelimit.py`：7 个用例，覆盖验收标准全部条目。
