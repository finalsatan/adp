### 2. 端到端用例 `frontend/e2e/tests/phase3.e2e.ts`

按知识库技术方案 19.3 的端到端一条，再加第三期的主要流程：

1. 搭建者建文档库（选指向本地假模型服务的向量化模型）→ 建文件夹 → 上传一个 PDF → 状态从排队中到已完成 → 文档数与分块数更新。
2. 命中测试：输入问题 → 向量/全文/融合/重排四步有结果和耗时 → 点结果“原文位置”打开 PDF 预览并高亮。
3. 上传一个 Word → 完成后打开解析结果视图，命中测试点结果高亮对应段落（固定样例）。
4. 文档操作：停用/启用、失败重试（让假解析服务对某个文件名返回失败）、重新解析（可改选方案）、批量删除。
5. 权限：协作者能上传和编辑，不能改可见范围、停用、删除；平级组织用户看不到该库。
6. 停用知识库后命中测试仍能跑，返回空结果（知识库已停用时跳过该库，2026-10-25 用户决定；知识库技术方案 12.1）。
