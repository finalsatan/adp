# P3-17 前端：命中测试

状态：待开始
前置：P3-01（联调需要 P3-13、P3-14）
被依赖：P3-19

## 目标

做出知识库的命中测试页：临时调整检索配置、按步骤查看向量召回/全文召回/融合/重排的结果与得分和耗时，点击结果打开原文位置，并能保存为默认配置。

## 依据

- 需求 4.1.7、4.1.9
- 知识库技术方案 12（检索实现，逐条对照）、16（接口清单）、17（权限、用量）
- 原型 `#v-kbhit`
- P3-01 契约

## 要做

### 1. 页面框架

- 路由 `/kb/:id/hit-test`（“检索与命中测试”页签）；页头与页签复用 P3-15 的 `KbHeader`。
- 文档库与问答库共用本页（需求 4.1.7）；第三期只联调文档库，问答库的分类过滤和问答对结果按契约预留。

### 2. 检索配置表单（照原型 `#v-kbhit`）

- 检索方式：向量、全文、混合；混合时权重（向量/全文，和为 1）。
- 召回数量 Top K、分数阈值，提示“开启重排时阈值作用于重排分数，未开启时作用于融合后的分数”。
- 重排：开关、重排模型（只列已启用的重排模型）、保留条数。
- 相邻分块扩展（前后各 N 块）：第三期隐藏该控件（第五期实现，2026-10-25 用户决定）；表单与提交对象里不出现 `adjacent_n`。
- 过滤：文件夹（全部文件夹 / 某文件夹含下级）、元数据条件（一层“且/或”多条件、不嵌套，字段与类型来自 P3-05）；问答库为分类过滤（按契约预留）。
- 默认值来自知识库的默认检索配置；“恢复默认”重置；“保存为默认配置”调 P3-04 的检索配置接口，需要编辑权限。

### 3. 命中测试

- 输入问题后点“测试”，调 `POST /kbs/{kb}/hit-test`（问题 + 临时检索配置）。
- 顶部步骤条：向量召回 N、全文召回 N、融合 N、重排 N；点击某一步切换下方结果列表。
- 耗时行照原型：“当前显示：重排后保留的 N 条（耗时：向量 X ms · 全文 Y ms · 重排 Z ms）”。
- 结果项：序号、分数、文档名、页码/位置、标题路径、内容（表格标记）、引用位置按钮。第三期问答库不联调。
- 点“原文位置”跳到 P3-18 的文档详情并定位（路由参数，如 `/kb/:id/documents/{docId}?chunk={chunkId}`）（补充）。
- 记录不保存；切换知识库或离开页面清空结果；模型用量来源记为“命中测试”（知识库技术方案 17，由后端 P3-13 记录）。

### 4. 权限

- 有查看权限即可用命中测试；“保存为默认配置”需要编辑权限（需求 4.1.9、技术方案 7.3）。
