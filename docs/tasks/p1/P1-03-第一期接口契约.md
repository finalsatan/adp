# P1-03 第一期接口契约

状态：已验收
前置：P1-01
被依赖：P1-02、P1-06 及之后全部一期任务

## 目标

把第一期全部接口的请求、返回结构和路由签名写出来，实现先留空（返回 501），生成 OpenAPI。之后前端按生成的类型开发，后端各卡只填实现，不改结构（技术方案 10：每期第一周先写契约）。

## 依据

- 技术方案 6、7、8.1、10、11
- 需求 10.1–10.8
- 原型：`#v-login` `#v-changepw` `#v-profile` `#v-users` `#d-newuser` `#d-edituser` `#m-resetpw` `#v-orgs` `#d-neworg` `#d-orgmembers` `#v-audit` `#v-overview` `#d-collab` `#v-settings`

## 要做

### 1. 枚举和公共结构

放在 `app/core/schemas.py`（公共）和各模块的 `schemas.py`：

- `Role`：`sys_admin`（系统管理员）、`org_admin`（组织管理员）、`builder`（搭建者）、`end_user`（终端用户）
- `UserStatus`：`active`、`disabled`
- `Visibility`：`private`（仅自己）、`org`（本组织）、`platform`（全平台）
- `ResourceStatus`：`enabled`、`disabled`
- `AuditResult`：`success`、`failure`
- `Page[T]`：`items: list[T]`、`total: int`；分页参数 `page`（≥1，默认 1）、`page_size`（1–100，默认 10）
- `UserBrief`：`id`、`username`、`name`
- `OrgBrief`：`id`、`name`
- 所有**请求**结构都设 `model_config = ConfigDict(extra="forbid")`：带了契约以外的字段返回 422，避免“传了 role 却被悄悄忽略”（补充）。返回结构不设。
- PATCH 请求里省略的字段表示不修改；可清空的字段（email、phone、remark）传 `null` 表示清空。

### 4. 接口

除标注“不需登录”的以外都要登录。“允许待改密”表示访问令牌带 `pwc=true` 时也能调用（技术方案 8.1），其余接口此时返回 403 `PASSWORD_CHANGE_REQUIRED`。

#### 认证 `app/auth/router.py`（tag：认证）

| 接口 | 请求 | 返回 | 说明 |
| --- | --- | --- | --- |
| `POST /api/v1/auth/login` | `{username, password}` | `{must_change_password: bool}`，并设置两个 Cookie | 不需登录 |
| `POST /api/v1/auth/refresh` | 无（读刷新令牌 Cookie） | `{must_change_password}`，并换发两个 Cookie | 不需登录 |
| `POST /api/v1/auth/logout` | 无 | 204，清除两个 Cookie | 访问令牌已过期也可以调用 |
| `POST /api/v1/auth/change-password` | `{old_password: str \| null, new_password}` | `{must_change_password: false}`，并换发两个 Cookie | 允许待改密；待改密时不要求原密码（补充，照原型 `#v-changepw`），否则必填 |
| `GET /api/v1/auth/policy` | — | `{password_min_length, password_min_classes, access_token_minutes}` | 允许待改密。改密页的规则提示和个人中心的“最迟 N 分钟后失效”用（补充） |

Cookie（技术方案 8.1）：访问令牌 `adp_at`，路径 `/api`；刷新令牌 `adp_rt`，路径 `/api/v1/auth/refresh`。都是 HttpOnly、SameSite=Strict，Secure 由配置 `COOKIE_SECURE` 决定。

## 注意

- 动作路由 `/users/{id}:disable` 这类写法里，Starlette 的 `{id}` 默认匹配除 `/` 外的任意字符，可能把 `5:disable` 整个当成 id 匹配到别的路由。路径参数一律写成 `{id:int}`（Starlette 的 int 转换器），并写测试确认：`POST /api/v1/users/5:disable` 进的是停用路由，`GET /api/v1/users:search?q=a` 进的是搜索路由，`GET /api/v1/users/abc` 返回 404。
- 契约是前后端共同的依据。以后实现时确实要改字段，先在卡片“问题”里提出来。
