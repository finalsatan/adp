# P1-04 第一期表结构迁移

状态：已验收
前置：P1-01
被依赖：P1-05 及之后全部一期后端任务

## 目标

用 SQLAlchemy 定义第一期的全部表，并写一个 Alembic 迁移建表。

## 依据

- 技术方案 6.1、6.2、6.4、12（数据库两个账号、审计表只增不改）
- 需求 10.2、10.3、10.6

## 要做

所有表：主键 `id bigint` 自增（`resource_members`、`settings` 除外）；时间字段 `timestamptz`，`created_at`、`updated_at` 默认 `now()`。

### users（`app/iam/tables.py`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| username | text not null | 存去掉首尾空格后的小写；唯一索引 |
| password_hash | text not null | argon2id |
| name | text not null | |
| email、phone、remark | text null | |
| status | text not null default 'active' | check：active / disabled |
| role | text not null | check：sys_admin / org_admin / builder / end_user |
| org_id | bigint null，FK orgs | 系统管理员为空 |
| must_change_password | boolean not null default true | |
| token_version | integer not null default 0 | |
| last_login_at | timestamptz null | |
| created_by | bigint null，FK users | 命令行创建的初始管理员为空 |
| created_at、updated_at | | |

- check 约束：`(role = 'sys_admin') = (org_id IS NULL)`（补充：系统管理员不属于组织，其他角色必须属于一个组织）。
- 索引：`org_id`、`role`。

### orgs（`app/iam/tables.py`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| parent_id | bigint null，FK orgs | 创建后不可修改 |
| path | text not null | 物化路径，如 `/1/5/12/` |
| name | text not null | |
| remark | text null | |
| created_by | bigint null，FK users | |
| created_at | | |
| deleted_at | timestamptz null | 软删除 |

- 索引：`path text_pattern_ops`（供 `LIKE '/1/5/%'`）；`parent_id`。
- 唯一索引：`(COALESCE(parent_id, 0), name) WHERE deleted_at IS NULL`（同一上级下不重名，顶级组织之间也不重名）。
- path 要在插入时就有值：先 `SELECT nextval(...)` 取 id，再拼 path 插入（实现在 P1-10，本卡只建表）。

### refresh_tokens（`app/auth/tables.py`）

`user_id`（FK users）、`session_id`（text，一次登录一个，uuid hex）、`token_hash`（text，唯一，SHA-256 十六进制）、`token_version`、`expires_at`、`revoked_at`（null）、`ip`、`user_agent`、`created_at`。索引：`session_id`、`user_id`。

### settings（`app/settings/tables.py`）

`key`（text 主键，为设置分组名，如 `password`）、`value`（jsonb）、`updated_by`（bigint null）、`updated_at`。

### resources、resource_members、resource_refs（`app/resources/tables.py`）

resources：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| type | text not null | kb / scheme / app …，第一期没有任何类型 |
| name | text not null | |
| description | text null | （补充：知识库、应用都有描述） |
| org_id | bigint not null，FK orgs | |
| owner_id | bigint not null，FK users | 创建人 |
| visibility | text not null | check：private / org / platform |
| status | text not null default 'enabled' | check：enabled / disabled |
| created_at、updated_at | | （补充：updated_at） |
| deleted_at | timestamptz null | （补充：应用删除是软删除，用量统计还要显示已删除应用的名称） |

- 唯一索引：`(type, org_id, name) WHERE deleted_at IS NULL`。
- 索引：`org_id`、`owner_id`、`type`。

resource_members：`resource_id`（FK resources）、`user_id`（FK users）、`added_by`（FK users）、`added_at`；主键 `(resource_id, user_id)`；索引 `user_id`。

resource_refs：`target_type`（text，check：model / resource）、`target_id`（bigint）、`ref_resource_id`（bigint，FK resources）、`created_at`；唯一 `(target_type, target_id, ref_resource_id)`；索引 `(target_type, target_id)`、`ref_resource_id`。

### audit_logs（`app/audit/tables.py`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| at | timestamptz not null default now() | |
| actor_id | bigint null | 不加外键（补充：审计表独立，不受其他表影响） |

### 迁移

- 一个迁移文件 `0001_phase1`，只写 upgrade。

### 和卡片不一致 / 需要说明

1. `orgs` 与 `users` 互相引用（`users.org_id → orgs`、`orgs.created_by → users`），`orgs.created_by` 的外键加了 `use_alter=True`。`alembic --autogenerate` 会把它内联进 `create_table('orgs')`，而 PostgreSQL 的 `CREATE TABLE` 不会建带 `use_alter` 的外键，导致外键缺失；迁移里手工改为在 `users` 建好之后 `op.create_foreign_key(...)` 补建。
2. `audit_logs` 的 `REVOKE UPDATE, DELETE, TRUNCATE` 放在迁移末尾，角色名取 `os.environ.get("ADP_APP_ROLE", "adp_app")`（卡片要求）。
3. 迁移的 `downgrade` 抛 `NotImplementedError`（开发约定：只做向前迁移），没有写回退逻辑。
4. `settings.value` 按“未标 null 即 not null”处理，`resources.target_id`、`resource_refs.target_id` 同理。
5. `token_hash`、`username` 按卡片写“唯一索引”，用 `Index(unique=True)` 而不是 `UniqueConstraint`。
6. 本卡没有改 Makefile（现有目标已够用）；Makefile 当前在工作区的改动是别的并行卡留下的，未纳入本次提交。
