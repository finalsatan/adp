### 2. 接口客户端 `src/api/`

- `schema.d.ts`：生成的类型，提交到仓库。
- `client.ts`：`createClient<paths>({ baseUrl: "", fetch: fetchWithRefresh })`。
- `fetchWithRefresh(request)`：
  - 先 `fetch(request.clone())`。
  - 返回 401、且请求地址不是 `/api/v1/auth/login`、`/api/v1/auth/refresh`、`/api/v1/auth/logout` 时：调用 `refreshOnce()`，成功则用原请求重试一次并返回重试结果；失败则跳转 `/login?redirect=<当前路径>`。
  - `refreshOnce()`：同一时刻只发一个 `POST /api/v1/auth/refresh`，其他调用等同一个 Promise（技术方案 11：同一标签页多个请求同时过期时只刷新一次）。
  - 返回 403 且 `code === "PASSWORD_CHANGE_REQUIRED"` 时跳转 `/change-password`。
  - 跳转用一个可替换的函数（便于测试），不要直接写死 `window.location`。
  - 导出 `fetchWithRefresh`，第二期的 SSE 读取工具会复用。
- `errors.ts`：从错误响应中取 `message`、`code`、`detail`；TanStack Query 的全局 `onError` 用 `message.error(...)` 显示后端返回的中文说明（未带说明时显示“请求失败，请稍后再试”）。表单页可以自行捕获并在表单上显示，此时不重复弹出。

### 3. 登录状态

- `useMe()`：TanStack Query 查询 `GET /api/v1/me`。
- `<RequireAuth>`：加载中显示 Spin；401 跳转登录页（带 redirect）；`must_change_password` 为 true 时跳转 `/change-password`。
- `usePermission(code)`、`hasPerm(me, code)` 工具函数。

### 4. 路由

| 路径 | 布局 | 页面（本卡放占位组件） | 显示条件 |
| --- | --- | --- | --- |
| `/login` | 无 | 登录（P1-13） | 不需登录 |
| `/change-password` | 无 | 首次改密（P1-13） | 已登录 |
| `/my-apps` | 我的应用布局 | 我的应用（P1-13） | 已登录 |
| `/profile` | 控制台 | 个人中心（P1-13） | 非终端用户 |
| `/system/users` | 控制台 | 用户管理（P1-14） | `user.manage` |
| `/system/orgs` | 控制台 | 组织管理（P1-15） | `org.manage` |
| `/system/overview` | 控制台 | 资源总览（P1-16） | `overview.view` |
| `/system/audit` | 控制台 | 审计日志（P1-16） | `audit.view` |
| `/system/settings` | 控制台 | 系统设置（P1-17） | `settings.manage` |
| `/` | — | 终端用户跳 `/my-apps`；其他角色跳侧栏第一个可见菜单，没有可见菜单时跳 `/profile` | — |
| 其他 | — | 404 页 | — |

- 终端用户访问控制台路由时跳转 `/my-apps`（技术方案 11、应用技术方案 11）。
- 有路由但没有权限码时显示 403 页（“没有权限访问该页面”），不跳走。
- 页面组件用 `React.lazy` 按路由拆包。

### 5. 控制台布局 `src/layouts/ConsoleLayout.tsx`

- 左侧菜单分组和顺序照原型：模型服务、资源库、应用开发、探索广场、系统观测、通用智能体、API Key、系统管理。**只显示已上线、且当前用户有权限的菜单项**；一个可见项都没有的分组整组不显示（补充：原型里“待细化”的灰色菜单和后续分期才做的模块，在上线前都不显示）。第一期只有“系统管理”下的五项。
- 菜单配置写成一个数组（分组、标题、路径、所需权限码），由纯函数 `buildMenu(me)` 过滤，便于测试；后续分期往数组里加项即可。
- 顶栏：左边面包屑（分组 / 页面，照原型 `.crumb`）；右边“我的应用”链接、用户菜单（头像取姓名首字、姓名；下拉里显示所属组织名称——系统管理员显示“系统管理员”，以及“个人中心”“退出登录”）。退出登录调用 `POST /api/v1/auth/logout`，清空查询缓存，跳 `/login`。
- 内容区放 `<Outlet />`。

### 6. 我的应用布局 `src/layouts/ChatLayout.tsx`

照原型 `#v-myapps` 的顶栏：左边平台名，右边“返回控制台”（终端用户不显示）和用户菜单。不带侧栏。

### 7. 公共组件和工具

- `PageHeader`：标题、说明、右侧操作按钮（照原型 `.page-head`）。
- `useTablePage()`：把 Ant Design Table 的分页和 `page`、`page_size`、`total` 对上，翻页、改每页条数时重新查询。
- `formatTime(iso)`：按浏览器时区显示 `YYYY-MM-DD HH:mm`；`formatRelative`（今天 09:12、昨天 17:05、10-19 11:03，照原型用户列表）。
- `labels.ts`：角色、用户状态、可见范围、资源状态的中文名。

- `request.clone()` 要在第一次发送前做，已经被读过 body 的请求不能再发。
- 不要把令牌存到 localStorage：令牌只在 HttpOnly Cookie 里，前端读不到也不需要读。
