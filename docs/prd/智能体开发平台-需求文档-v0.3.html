智能体开发平台 需求文档

v0.3 · 2026-10-21 · 草稿

读者：研发团队。本版只列出大的功能模块，并说明每个模块需要做什么。优先级、详细功能和验收标准在后续版本中逐个补充。

1. 功能模块一览

编号模块一句话说明
M1模型服务统一接入和管理平台使用的各类模型

2. 各模块需要做的事情

M1 模型服务

目标：让平台能统一使用各类模型，使用者不用关心接入细节。
  • 接入对话（Chat）、向量化（Embedding）、重排（Rerank）、OCR/视觉（VLM）等类型的模型。
  • 系统管理员配置全平台共享的模型；组织管理员可追加本组织自己的模型与密钥。
  • 模型密钥加密保存，界面和接口不暴露明文。
  • 可测试模型是否可用；可启用、停用模型。
  • 提供在线对话体验，并支持多个模型对比效果。

M2 资源库

目标：把应用开发要用的素材集中管理，一次建好、多处引用。
  • 知识库（重点）：上传、更新、删除文档并查看解析进度与失败原因；配置解析与分块方式；查看和编辑分块；配置检索并用命中测试验证召回效果；按用户授权。后续补充问答对与同义词、入库时的上下文增强、外部数据源同步。
  • MCP 服务：接入外部 MCP Server，并按工具粒度启用。
  • 插件工具：提供内置工具，并支持导入 OpenAPI 描述的自定义工具。
  • 提示词：管理提示词模板与版本，并支持对提示词做评测。
  • Skills：管理技能包，并在沙箱中执行。
  • 安全护栏：对输入输出做过滤，支持敏感词与提示词注入检测。
  • 所有资源可见范围分三档：仅自己、本组织、全平台，并能被应用以统一方式引用。

M3 应用开发

目标：让搭建者把模型和资源组合成可用的应用，并发布出去。
  • 知识问答（重点）：基于知识库的问答应用；检索策略按应用配置；支持多轮对话；回答带引用，点击可定位到原文；每次问答可调试回放。
  • 工作流（重点）：可视化编排，支持分支、循环、并行、人工介入与断点续跑。
  • 智能体：组合模型、知识库、工具、MCP 与记忆，支持多步检索与推理。
  • 应用发布：发布为 Web 对话页（含手机浏览器）、嵌入组件和 API；终端用户可查看历史会话，并对回答点赞、点踩、纠错。

M4 探索广场

目标：让大家发现并复用已有成果，减少重复搭建。
  • 应用广场：浏览并使用发布到全平台的应用。
  • 模板、MCP、Skill 广场：复用模板和共享资源。

M5 应用观测

目标：让运行情况和问答效果可见、可衡量。
  • 统计看板：展示调用量、Token 用量与活跃度（仅统计，不计费）。
  • 链路追踪（重点）：回放每次对话的查询改写、召回、重排、上下文与模型调用。
  • 效果评测（重点）：评测集可来自人工导入、大模型按文档生成、终端用户点踩转入；衡量召回、答案正确性、引用准确性与拒答；同一评测集可对比两套检索配置。

M6 通用智能体

目标：给全体员工一个开箱即用的助手，不需要自己搭建。
  • 提供面向全员的通用 AI 助手入口。

M7 API Key 管理

目标：让外部系统安全地调用平台上的应用。
  • 创建、吊销 API Key，并绑定到具体应用。
  • 后续支持细分权限范围。

M8 系统管理

目标：管好谁能用、能用什么，并留下可追溯的记录。
  • 用户与组织：多级组织树，对应子公司、部门；一个用户可属于多个组织并切换当前组织。
  • 角色与权限：组织内可自定义角色；系统管理员可建全局角色；菜单与操作权限按角色控制。
  • 资源归属与隔离：所有资源与应用记录所属组织和创建人，数据按组织隔离。
  • 单点登录与运营管理：对接公司统一登录，提供平台运营所需的管理能力。
  • 审计：对权限变更、发布、删除、密钥操作等关键动作留日志。
