# 每个用户只属于一个组织，角色固定，资源统一用可见范围加协作者控制

最初的设计参考万悟：一个用户可加入多个组织并切换“当前组织”，同一组织内可有多个自定义角色（权限取并集），另有全局角色，知识库单独按用户授予查看、编辑、授权三档。评审发现这套规则复杂，而且有实际漏洞：组织管理员能把其他组织的管理员拉进本组织再重置其密码，接管账号；审计和资源归属也因为“当前组织”变得含糊。2026-10-22 改为：每个用户只属于一个组织、只有一个角色；角色固定为系统管理员、组织管理员、搭建者、终端用户四个；所有资源用同一套规则，即可见范围（仅自己、本组织含下级、全平台）加协作者（可编辑一档）。组织管理员管理本组织及下级组织的全部用户和资源，由系统管理员或上级组织的组织管理员任命；不做组织停用。

**Consequences**：一个人不能同时挂在两个部门，跨部门协作靠协作者或全平台可见；不能自定义角色，以后需要时再加；不能单独给某人只读权限。之后改回多组织成员制要迁移用户、权限和审计数据，代价较大。
